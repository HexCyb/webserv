What a browser sends to webserv:

    GET /files/hello.txt HTTP/1.1      <- request line: method, target, version
    Host: localhost:8080               <- headers, one per line
    Connection: keep-alive
                                       <- an empty line ends the headers
    (body, only for POST)              <- its size is in Content-Length,
                                          or it comes in chunks (Transfer-Encoding: chunked)
